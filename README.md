## 🚀 Featured Projects

### 🌦️ Weather Report Using Power BI

An interactive **Power BI weather analytics dashboard** that turns weather data into dynamic reports, letting users explore current conditions, forecasts, and weather trends.

* **Focus:** Data Visualization • Dashboards • Weather Analytics
* **Tech:** Power BI
* 🔗 [View Repository](https://github.com/APatel-1305/Weather-Report-Using-Power-BI)

---

### 🧠 Explainable Sentiment Analysis

An **Explainable AI (XAI)** sentiment analysis app that predicts the sentiment of user-entered text and shows which words and features influenced each prediction, moving beyond "black box" models.

* **Pipeline:** Text Cleaning → Tokenization → TF-IDF → ML Model → Sentiment Prediction → Explanation
* **Tech:** Python, Scikit-learn, Pandas, NumPy, NLTK, Matplotlib, Streamlit
* 🔗 [View Repository](https://github.com/APatel-1305/Explainable-Sentiment-Analysis)

---

### 🩺 BioBERT Medical Assistant

A medical question-answering assistant built around **BioBERT**, combining a trained BioBERT ranker with a **FAISS vector store** to retrieve relevant responses from preprocessed medical dialogues.

* **Focus:** Biomedical NLP • Retrieval • Response Ranking • Vector Search
* **Tech:** Python, BioBERT, FAISS
* 🔗 [View Repository](https://github.com/APatel-1305/biobert-medical-assistant)

<sub>⚠️ Built for learning and research. Not a substitute for professional medical advice.</sub>
